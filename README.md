# Política de Privacidad

Última actualización: 02 de octubre de 2026

## Información recopilada

Esta aplicación no recopila, transmite ni comparte datos personales con el desarrollador ni con terceros.

Toda la información ingresada por el usuario se almacena únicamente en el dispositivo donde la aplicación está instalada.

## Uso de la información

Los datos almacenados se utilizan exclusivamente para el funcionamiento de la aplicación y permanecen en el dispositivo del usuario.

## Compartición de datos

La aplicación no comparte información con terceros.

## Servicios externos

La aplicación no utiliza servicios de publicidad, seguimiento ni análisis de usuarios.

## Seguridad

La información permanece almacenada localmente en el dispositivo.

## Eliminación de datos

El usuario puede eliminar toda la información desinstalando la aplicación.
